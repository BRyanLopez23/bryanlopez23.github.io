# 🌐 Portafolio Web — Bryan Francisco López León

Sitio web profesional y portafolio interactivo de **Bryan Francisco López León** (Estudiante de 8vo Semestre de Ingeniería en Software — Universidad de Guayaquil).

🔗 **URL en vivo (GitHub Pages):** [https://bryanlopez23.github.io](https://bryanlopez23.github.io)

## ✨ Características
* **Diseño Moderno Dark Mode:** Cuadrícula técnica con luces radiales y tipografía con gradiente Cyan/Violeta.
* **Selector de Idioma en Vivo (`ES | EN`):** Traducción instantánea entre español e inglés.
* **Descarga Directa de CV:** Incluye tanto la versión Ejecutiva como la versión optimizada para filtros ATS en PDF.
* **Secciones Integradas:** Proyectos destacados (`NexStock ERP`, `TaskFlow Pro`, `Python & SQL Algorithms Lab`), Stack Tecnológico, Formación Académica y Contacto directo vía WhatsApp.
